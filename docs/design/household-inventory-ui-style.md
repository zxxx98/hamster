# 家庭库存 App UI 样式指南

## 视觉定位

**自然生活感 × 瑞士极简**：外在温暖、内部克制的“安静家庭管家”。

界面应让成员快速判断三件事：家里还有没有、数量是多少、放在哪里。真实存放点照片承担生活感与定位作用；常规操作界面优先信息密度、留白和可扫描性。

## 设计原则

- 以暖白背景、深色文字和自然的鼠尾草绿建立可信、放松的基调。
- 扫码入库是唯一持续突出的主操作。
- 数量、低库存状态和存放位置优先于装饰图标。
- 使用细分隔线和布局分区组织内容；仅在需要承载独立交互时使用卡片。
- 低库存仅使用砖红/陶土橙作为状态色，不引入多种竞争性的强调色。
- 位置照片是实用信息，展示在物品详情和位置详情中，不铺作页面背景。

## 颜色

| 语义 | 色值 | 用途 |
|---|---|---|
| 页面底色 | `#F6F3EC` | 全局背景、移动端主画布 |
| 表面 | `#FFFDFA` | 弹层、底部导航、需要与底色分层的区域 |
| 主文字 | `#28332D` | 标题、数量、主要操作文字 |
| 次要文字 | `#798078` | 元数据、时间、辅助说明 |
| 分隔线 | `#DFDDD5` | 列表行、导航分区、表单边界 |
| 主强调色 | `#5E7966` | 扫码按钮、已选导航、可点击文字、正向状态 |
| 主色浅层 | `#E5ECE3` | 已选导航、柔和的强调背景 |
| 低库存 | `#C77845` | 数量告警、提醒侧边线、需要补货状态 |
| 低库存浅层 | `#F7EBE1` | 低库存提醒容器 |

页面只使用鼠尾草绿作为品牌/操作色。低库存色只表达风险，不能被用于普通按钮或装饰。

## 字体与层级

- 标题：中文衬线字体优先（`Noto Serif SC`、`Songti SC`），营造家庭物品目录般的温度。
- 正文与控件：中文无衬线字体（`Noto Sans SC`、`PingFang SC`），保证密集库存信息可读。
- 大标题：30–38 px，衬线，字距略紧。
- 分区标题：19–26 px，衬线。
- 物品名称：16–18 px，无衬线，半粗或粗体。
- 数量：24–30 px，衬线；单位紧随数量，以 12–14 px 次要文字呈现。
- 元数据：12–14 px，无衬线，使用次要文字色。

不使用超过两种字体，不将渐变用于文字，也不使用过浅的灰色文字。

## 布局

### PC

- 左侧固定导航栏：品牌、首页、库存、低库存、位置、操作记录；底部显示家庭名称和同步状态。
- 主内容区从“当前状态”开始：问候/概览、低库存提醒、常用物品列表。
- 常用物品采用纵向列表，不使用 KPI 卡片拼贴。每行依次为商品包装缩略、名称与规格、数量、房间与存放点。
- 顶部右侧保留“扫码入库”主按钮。

### 移动端

- 首页优先显示低库存提醒与常用物品；减少辅助说明，保留数量和位置。
- 底部导航为：首页、库存、位置、我的。
- 圆形悬浮扫码按钮位于底部导航上方中央，是移动端最醒目的操作。
- 录入、取用、补货使用底部抽屉或全屏流，避免在小屏内堆叠表单。

## 组件规则

- 圆角：页面大容器 20–24 px；按钮 9–12 px；列表和普通信息区可无外框。
- 阴影：只用于浮层、移动端设备预览和主按钮的轻微抬升；日常列表不用厚阴影。
- 按钮：主按钮为鼠尾草绿底、白字；次按钮为透明或暖白底配细边界；危险操作仅在确认弹层中使用低库存色。
- 列表：通过一像素分隔线分行；不要给每一行套独立卡片。
- 商品缩略：优先使用条码查询得到的包装图；无图时使用低饱和的包装色占位，不使用花哨插图。
- 照片：存放位置照片在详情中以清晰矩形缩略图呈现，配合“厨房 / 水槽下方柜”文字，不依赖照片本身传达位置名称。

## 状态与交互

- 低库存：首页每次打开时显示简洁提醒；列表中的低数量以砖红数字标记。
- 忽略提醒：不改变库存的低库存状态，只关闭提醒展示；恢复后立即重回提醒区。
- 扫码：点击主按钮后快速进入相机，不额外经过功能选择页。
- 数量变化：补货、取用和用完后使用短暂数字更新动画；不做弹跳或大幅缩放。
- 界面切换：抽屉、弹层和页面内容使用快速淡入/平移过渡；尊重 `prefers-reduced-motion`。
- 同步：在家庭信息或操作附近显示“刚刚同步 / 待同步 / 同步失败”，不以侵入式弹窗打断日常操作。

## 明确避免

- SaaS 仪表盘式的多张统计卡片拼贴。
- 霓虹、赛博朋克、深色科技风和强烈玻璃拟态。
- 大面积渐变、多个品牌色、装饰性图标堆叠。
- 过度圆润的拟物组件、厚重阴影和浮夸点击动画。
- 用图片代替房间、存放点和数量等关键文字信息。
